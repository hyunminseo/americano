# 오프라인 라이선스 운영

앱은 네트워크 서버 없이 Ed25519 서명, 제품 ID, 발급/시작/만료 UTC 시각, MAC 해시, `macro.run` 권한을 확인한다. MAC은 대소문자와 `:`/`-` 표기를 정규화하며 라이선스에 원본 MAC 대신 제품별 해시를 저장한다. IP가 없는 어댑터는 Windows getmac.exe로 비동기 조회하며 조회할 수 없을 때 인증을 우회하지 않는다.

## 키와 발급

공개키는 `licensing/public-key.pem`, 발급 개인키는 `.local/license-issuer/private.pem`에 있다. 개인키와 발급 스크립트는 앱 배포물에 포함하지 않는다. `.local`은 Git에서도 제외한다. 발급 개인키는 별도 안전한 위치에 백업해야 하며 소스 공유나 EXE 배포에 첨부하지 않는다. 공개키만 남아 있고 개인키가 사라졌으면 자동으로 새 키를 만들지 않고 복원을 요구한다.

```powershell
npm.cmd run license:init
node scripts/license-issuer.cjs issue --mac XX:XX:XX:XX:XX:XX --to "사용자 이름" --expires "2027-09-05T00:00:00.000Z" --out .local/customer.lic
```

`license:init`은 기존 키를 재사용한다. 발급 출력 파일도 기존 파일을 덮어쓰지 않는다. 생성한 `.lic`는 사용자에게 전달하고 앱의 **라이선스 등록**에서 선택한다. 등록 시 크기(최대 32KB), 형식, 서명, 제품, MAC, 기간, 기능 권한을 검증하며 잘못된 파일은 기존 라이선스를 교체하지 않는다. 만료가 연장된 새 파일도 같은 방식으로 등록한다.

## 실행 정책

만료일은 UTC이며 그 시각 이상이면 즉시 새 권한 검사를 거부한다. 앱은 1초마다 만료를 감시해 실행 중 대기/일시정지도 중단하고, 실제 실행기에서도 매 단계 전에 재검증한다. UI를 열어 둔 상태에서 만료되면 상태가 자동 갱신된다. 사용자 매크로는 삭제하지 않고 편집과 입력 없는 미리보기를 계속 허용한다. 라이선스 등록은 매크로 데이터 저장소에 손대지 않는다.

MAC 주소는 변경될 수 있으며 완전 오프라인이므로 시스템 시계 조작과 로컬 앱 코드 변조까지 막는 보장은 없다. MachineGuid와 UUID 바인딩은 이번 사용자 요청에 따라 사용하지 않는다.

## 비교 빌드와 진단

`npm run build:license-compare -- --mac MAC`은 지정한 로컬 MAC과 현재 PC에 없는 로컬 관리 MAC으로 30일짜리 라이선스를 발급하고 각 EXE에 내장한다. 라이선스 원본은 `.local/license-comparison`에 저장한다. 일반 `build.bat`은 공개키만 포함한 미등록 앱을 만든다.

포터블 EXE에 `--license-diagnostics`를 전달하면 UI/입력을 시작하지 않고 동일한 라이선스 검증을 실행해 종료한다. 인증 성공은 종료 코드 0, 실패는 2다. 이미 같은 비교 앱이 실행 중이면 single-instance 처리에 영향을 받으므로 먼저 종료한다. 앱을 평소처럼 실행하면 상세 실패 원인과 만료일을 볼 수 있다.

비교 빌드는 라이선스 인증 성공/실패를 확인한다. 대상 창 제어 및 실제 키/마우스 입력 기능의 완료를 의미하지 않는다.
